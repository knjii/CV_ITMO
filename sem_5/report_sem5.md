# Отчет по подготовке задания sem_5

## Цель

Подготовить `qwen_label_image.ipynb` к самостоятельному запуску для автоматической разметки изображений из папки `data` с использованием vision-language модели на GPU.

## Что сделано

### 1. Скачан датасет

Изменения:
- Загружены изображения из репозитория задания.
- Данные размещены в `sem_5/data`.
- Проверено количество файлов: 174 изображения.

Причина:
- В исходной папке `sem_5` датасет отсутствовал, поэтому ноутбук не мог выполнить разметку всей папки `data`.

Измененные файлы:
- `sem_5/data/*`

### 2. Ноутбук переведен с Qwen на SmolVLM

Изменения:
- В `sem_5/qwen_label_image.ipynb` модель по умолчанию заменена на `HuggingFaceTB/SmolVLM-256M-Instruct`.
- Убрана зависимость от локального каталога `./models/qwen2.5_vlm_2b`.
- Убраны Qwen-специфичные импорты `Qwen2VLForConditionalGeneration`, `BitsAndBytesConfig`, `qwen_vl_utils`.
- Добавлена загрузка модели через `transformers`:
  - `AutoProcessor`
  - `AutoModelForImageTextToText` с fallback на `AutoModelForVision2Seq`

Причина:
- На GPU NVIDIA GeForce GTX 1650 Ti с 4 ГБ памяти Qwen2.5-VL-2B может не поместиться или потребовать дополнительной настройки квантизации.
- В условии разрешено использовать `SmolVLM-256M-Instruct`, если ресурсов для Qwen2.5-VL-2B недостаточно.

Измененные файлы:
- `sem_5/qwen_label_image.ipynb`

### 3. Добавлена обязательная проверка GPU

Изменения:
- Добавлен `assert torch.cuda.is_available()`.
- Модель явно переносится на `cuda:0`.
- Входные тензоры также переносятся на GPU.
- В ноутбуке печатаются версия PyTorch, CUDA и имя GPU.

Причина:
- По требованию запуск модели должен идти на GPU.
- Если ноутбук будет запущен в окружении без CUDA, он остановится до начала разметки, а не начнет медленную CPU-инференцию.

Измененные файлы:
- `sem_5/qwen_label_image.ipynb`

### 4. Промпт переписан на английский язык

Изменения:
- Добавлен английский промпт для описания изображений одним информативным предложением.
- Промпт просит описывать видимые объекты, сцену, действия, цвета и важный контекст без выдуманных деталей.

Причина:
- Для `SmolVLM-256M-Instruct` в условии отдельно указано, что промпты нужно писать на английском языке.

Измененные файлы:
- `sem_5/qwen_label_image.ipynb`

### 5. Добавлена пакетная разметка всей папки `data`

Изменения:
- Ноутбук автоматически ищет изображения с расширениями `.jpg`, `.jpeg`, `.png`, `.bmp`, `.webp`.
- Добавлен smoke-test на первом изображении.
- Добавлен цикл разметки всех изображений.
- Разметка сохраняется после каждого изображения.
- Добавлена возможность продолжить запуск после прерывания: уже размеченные файлы читаются из `labels_smolvlm.jsonl` и пропускаются.

Причина:
- Задание требует разметить данные в папке `data`, а не одно тестовое изображение.
- Сохранение после каждого изображения снижает риск потерять результат при долгом запуске.

Измененные файлы:
- `sem_5/qwen_label_image.ipynb`

### 6. Добавлено сохранение результатов в двух форматах

Изменения:
- Основной файл результата: `sem_5/labels_smolvlm.jsonl`.
- Дополнительный табличный файл: `sem_5/labels_smolvlm.csv`.
- Для каждой записи сохраняются:
  - `file_name`
  - `image_path`
  - `caption`
  - `model`
  - `prompt`

Причина:
- `jsonl` удобен для продолжения прерванной разметки.
- `csv` удобен для просмотра и дальнейшей обработки.

Измененные файлы:
- `sem_5/qwen_label_image.ipynb`

## Как запускать

1. Открыть `sem_5/qwen_label_image.ipynb`.
2. Выбрать Python kernel из окружения с CUDA/PyTorch.
3. Запустить все ячейки сверху вниз.
4. В ячейке проверки GPU должно быть напечатано имя видеокарты.
5. После завершения появятся файлы:
   - `sem_5/labels_smolvlm.jsonl`
   - `sem_5/labels_smolvlm.csv`

## Важные замечания

- Первый запуск может быть долгим: notebook скачает недостающие Python-пакеты и веса модели с Hugging Face.
- Если CUDA недоступна, ноутбук остановится на проверке `torch.cuda.is_available()`.
- Разметка не была запущена в рамках подготовки: ноутбук подготовлен для самостоятельного запуска пользователем.
